# 🏛️ Pabellón Universitario

Plataforma web diseñada para optimizar la gestión, registro y aprobaciones administrativas del comercio dentro de instalaciones universitarias. Proporciona una solución digital centralizada para administradores y vendedores, mejorando la logística y la visibilidad de los negocios locales mediante representación espacial.

## ✨ Características Principales

* 🔐 **Gestión de Accesos:** Sistema de autenticación seguro para diferentes roles de usuario (Administrador/Vendedor).
* 🗺️ **Mapa Interactivo:** Visualización y ubicación espacial de los vendedores en sus respectivas mesas dentro del pabellón.
* 📢 **Módulo de Promoción:** Espacio dedicado para la difusión de negocios, catálogos y productos.
* ☁️ **Almacenamiento en la Nube:** Persistencia de datos y gestión de archivos en tiempo real.

## 🛠️ Stack Tecnológico

**Frontend:**
* HTML5 & CSS3
* Vanilla JavaScript 

**Backend & Servicios (BaaS):**
* Firebase Authentication
* Firebase Realtime Database / Firestore
